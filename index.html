      Pengaturan

      Mochi bekerja hybrid: hal yang dia yakin dijawab instan oleh otak lokal (tugas, matematika, memori, power), sisanya dipakai LLM — gratis tanpa key (best-effort), atau pakai API key sendiri di bawah. Key juga bisa ditaruh di file .env di folder app (server-side, permanen — tidak hilang walau ganti device/data browser dibersihkan). Salin .env.example → .env.

      Key gratis: console.groq.com (Groq, paling cepat) · deepseek.com · sumopod.com

      🎙️ MiMo TTS (opsional) — Suara AI natural dari Xiaomi. Dapat API Key gratis di mimo.mi.com.
